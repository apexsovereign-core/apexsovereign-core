# L0 Summary — ApexSovereign.ai Resources

ApexSovereign.ai is a serverless compute-unit (CU) economy. The financial backbone is `api/webhook.js`, which receives PayPal `PAYMENT.CAPTURE.COMPLETED` events, validates a static authorization token, and credits user accounts via the Supabase RPC `credit_user_account` ($1.00 USD = 100 CU) with an atomic double-entry ledger. Supabase project ref: eeclrffbjbnapsajmtqn. Memory is provided by `@agentmemory/agentmemory` (BM25, zero-DB). Context compression via OpenViking (L0 -> L1 -> L2).
