How it works

Prepay, reserve, run, settle.

  1. Prepay credits

    Buy Compute Units at $1.00 = 100 CU. Credits are added only after the billing service confirms the payment.

  2. Price the fleet

    Pick an accelerator, fleet size and term. Rates come from the reference catalog until a supplier feed is connected.

  3. Provision

    Nodes are 8-GPU units. In supplier mode, allocation moves credits into escrow. In simulated mode nothing is charged and responses carry demo: true.

  4. Settle

    Each credit and debit is a double-entry ledger row. PayPal webhooks are verified with PayPal's signature API before any credit is written.

SimulatedDevelopers

One endpoint to provision.

Send a bearer key and an idempotency key. Keys are issued server-side after sign-in, and the browser never generates them. In simulated mode the response includes demo: true.

cURL
curl -X POST "https://www.apexsovereign.ai/v1/clusters/provision" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "H100 SXM5",
    "region": "us-ashburn",
    "nodes": 4,
    "term": "on-demand"
  }'
Python
import uuid
import requests

res = requests.post(
    "https://www.apexsovereign.ai/v1/clusters/provision",
    headers={
        "Authorization": "Bearer YOUR_API_KEY",
        "Idempotency-Key": str(uuid.uuid4()),
    },
    json={
        "model": "H100 SXM5",
        "region": "us-ashburn",
        "nodes": 4,   # 8 GPUs per node
        "term": "on-demand",
    },
)
print(res.json())
